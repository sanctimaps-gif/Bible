Assistant biblique

Une IA qui répond aux questions sur la Bible sans jamais inventer : chaque phrase qu'elle avance vient d'un texte qu'elle est allée lire.

Ce qu'elle sait faire

  • Reconnaître une scène biblique sur une image Elle relève les indices — les personnages, les gestes, les objets —, formule des hypothèses, puis les vérifie dans le texte avant de conclure.
  • Raconter l'histoire d'un prophète « Raconte-moi l'histoire du prophète Jonas. »
  • Répondre à une question de fond « Que dit le Nouveau Testament sur la tromperie ? »
  • Donner les lectures de la messe Pour aujourd'hui ou pour n'importe quelle date, dans la zone liturgique de votre choix.

Ses deux seules sources

SourcePour
aelf.org Le texte biblique dans la traduction liturgique officielle, et les lectures de la messe
sanctimaps.fr Les questions sur les saints

Ce n'est pas une consigne donnée à l'IA, c'est une contrainte inscrite dans le programme : elle n'a aucun accès au web, seulement cinq outils branchés sur ces deux sites, et chaque requête vérifie le domaine avant de partir. Si elle ne trouve pas, elle le dit — elle ne comble jamais un vide de mémoire.

Pour l'utiliser

Cette page ne peut pas être l'assistant

Elle est hébergée par GitHub Pages, qui ne sert que des fichiers — il n'y a personne derrière pour travailler. Et surtout : l'assistant a besoin d'une clé d'accès à l'IA, qui serait lisible par tous les visiteurs si elle était placée dans une page web. Il lui faut donc un serveur, même tout petit.

Sur votre ordinateur, quatre commandes suffisent :

git clone https://github.com/sanctimaps-gif/Bible.git
cd Bible
pip install -r requirements.txt
# collez votre clé API dans un fichier .env, puis :
uvicorn app.api:application

L'assistant répond alors sur http://127.0.0.1:8000.

Pour une adresse publique, l'application est livrée avec son image Docker et fonctionne chez n'importe quel hébergeur qui accepte Docker. Le dépôt explique la marche à suivre.

Voir le dépôt Guide d'installation
